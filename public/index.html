🎬 Netflix / Prime / Hotstar saath

  1. Dono apni Netflix / Prime app mein same movie kholo.
  2. Neeche time likho, aur dono movie ko isi time par rok do.
  3. Dono Ready dabao — dono ready hote hi ek saath 3-2-1 aayega, PLAY par play daba do.

Beech mein rokna ho to "Dono pause" dabao — partner ke phone par bara alert aayega. Wapas chalane ke liye dobara time likh kar dono Ready dabao.

Laptop par sab khud sync hota hai — play, pause, aage-peeche. Netflix, Prime Video, Hotstar aur YouTube sab par.

  1. Chrome mein hamara extension install karo (README mein tareeqa hai).
  2. Extension mein yehi server link, room naam aur password daalo.
  3. Site par same movie kholo — "EZOX Duo · Connected ✓" aayega.
  4. 🪟 button se call chhoti window bana lo taake movie ke upar ek doosre ko dekh sako.
